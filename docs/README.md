# Compliance pack

Working drafts for the paperwork side of running an asynchronous telehealth pharmacy. The software already
implements the technical safeguards; these documents cover what the rules ask you to write down, decide, and train on.

**Have healthcare counsel review everything here before you rely on it.** Names, states, and vendors are filled in
for Safer Pharmacy, Inc. and will need checking against your licenses and contracts.

| File | What it's for |
|---|---|
| `hipaa-security-plan.md` | Your Security Rule policies, mapped to what the platform actually does |
| `risk-analysis.md` | The required risk analysis, started for you, with the gaps that need decisions |
| `breach-response.md` | What to do in the first 72 hours, and the notification deadlines |
| `workforce-training.md` | What each role must be trained on, with a sign-off sheet |
| `vendors-and-baas.md` | Every vendor that touches health information and the agreement each needs |
| `telehealth-compliance.md` | How the asynchronous visit is structured and the state rules that shape it |
| `pharmacy-operations.md` | Pharmacy-side requirements: licensing, records, compounding, shipping |
